# Rule packs

Rules a study takes on besides the core rules of its `AGENTS.md`, one pack per kind of work. A study selects its packs in the Rule packs section of its `PLAN.md`; `ws spawn` copies every pack of this folder into the study's `rules/`, and `ws check` fails a study that selects a pack it does not have. Cite a rule by pack and number: `fe-simulation` 2.

The template's packs are `ml-training`, `fe-simulation`, `uq-reliability` and `literature-check`. A workspace adds its own here, one Markdown file each, in the same form: a title, one paragraph on when the pack applies, numbered rules.
